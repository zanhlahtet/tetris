# Tetris

A faithful Tetris Guideline-style clone for iOS and Android, built with Godot 4.7
and typed GDScript. Portrait, offline, single-player Marathon.

- Rules and scoring: `docs/GAME_RULES.md`
- Architecture and development workflow: `CLAUDE.md`
- Building and installing on a phone: `docs/BUILDING.md`

Run on desktop: `godot --path .` (keyboard: arrows, Space, Z/X, C, P, M, G, R).
Run the tests: `godot --headless --path . --script res://tests/run_tests.gd`.
